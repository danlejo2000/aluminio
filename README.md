# Aluminios OTTO - Sitio Web Corporativo

Sitio web profesional para Aluminios OTTO, distribuidor líder de perfilería de aluminio en Colombia.

## 🚀 Tecnologías

- **React 19** + **Vite 7** - Framework moderno y ultra-rápido
- **Tailwind CSS** - Diseño responsive y componentes
- **React Context API** - Gestión de estado global
- **React PDF** + **react-pageflip** - Catálogo interactivo
- **SEO Optimizado** - Posicionamiento profesional en buscadores

## 📦 Instalación

```bash
npm install
npm run dev
```

## 🎯 SEO Implementado

### ✅ Meta Tags Completos
- Títulos optimizados con keywords principales
- Descripciones únicas por sección
- Open Graph para redes sociales (Facebook, Twitter)
- Geo-targeting para Bogotá, Colombia

### ✅ Schema.org Structured Data
- LocalBusiness markup completo
- Product schemas dinámicos
- BreadcrumbList para navegación
- AggregateRating implementado

### ✅ Archivos SEO
- `sitemap.xml` - Mapa del sitio completo
- `robots.txt` - Directivas para crawlers
- `manifest.json` - PWA y mobile SEO
- `.htaccess` - Configuración Apache/Nginx
- `_redirects` - Para Netlify/Vercel

### ✅ Performance
- Lazy loading de imágenes
- Preconnect a Google Fonts
- DNS prefetch para servicios externos
- Video hero con poster image
- Compresión GZIP configurada

## 🌐 Deploy

### Netlify/Vercel:
```bash
npm run build
```
Los archivos `_redirects` y headers ya están configurados.

### Apache/Nginx:
El archivo `.htaccess` incluye configuración completa de:
- Redirecciones HTTPS
- Compresión GZIP
- Headers de seguridad
- Caché del navegador
